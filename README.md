# Projeto Aula 06 — Práticas de Git e GitHub

Uma aplicação em Python desenvolvida durante as aulas práticas com foco no aprendizado de fluxos de versionamento avançados, segurança de repositórios e boas práticas com Git/GitHub.

---

## 🚀 Funcionalidades e Aprendizados

- **Conventional Commits:** Mensagens de commit padronizadas (`feat:`, `fix:`, `docs:`, `refactor:`).
- **Automação com Issues:** Fechamento automático de tarefas no GitHub via mensagens de commit (`Closes #N`).
- **Gestão do `.gitignore`:** Exclusão de arquivos temporários, ambientes virtuais e arquivos do sistema.
- **Segurança e Sanitização:** Remoção de dados sensíveis (`config.local.json`) do rastreamento usando `git rm --cached`.

---

## 🛠️ Pré-requisitos

- [Python 3.10+](https://www.python.org/)
- [Git](https://git-scm.com/)
